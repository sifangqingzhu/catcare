# 7天单猫基线 → 共享采集 → 异常报警与差异定位

## 业务流程

共享盆允许多只猫一起使用。铲砂时逐块称量尿团/便块，不需要判断每块属于谁。应用先检测共享样本是否偏离正常基线，再使用整批正常与异常数据比较候选猫，不把正常共享记录变成待认领任务。

1. **前7天建议单猫隔离采样**：选择“单猫隔离基线”，明确猫咪身份，保持猫砂、等待时间、称量方式一致。尿团、大便分别积累，每行一个完整尿团/便块，碎片合并称量。
2. **未来共享盆逐块采集**：一次最多30块，可混合尿团和大便。各块保留自己的维度，共用时间、盆、批次号；事务保存，非法一块则全批不保存。
3. **异常优先**：正常共享样本无需归属。超出全部已完成的单猫正常基线范围时，直接产生共享池报警。
4. **差异缩小范围**：同时利用其他正常样本，检验哪只猫的正常特征改变更能解释整批数据；满足区分条件时显示优先排查猫，否则只报警。

## 基线隔离与冻结

界面在记录页提供“7天基准”入口。按猫、尿团/大便分别展示已采样日期数、有效样本数、首周日期范围及就绪状态；展开后可以按猫查看7格日历与典型重量/直径。当天多条记录不会增加采样日数。共享采集弹窗检查所选猫砂盆、猫砂版本和本次采集类型对应的基准，不把未完成的基准显示为可用。

- 记录模式为 `baseline/shared/observed`。共享记录 `CatID=null`；基线须指定猫、单份、有重量、无血迹/用力/无产出。个体异常用 `observed`。
- 基线按 `猫 × 猫砂配置版本 × 尿/便类型` 分组，隔离盆和共享盆可以不同，但须使用同一猫砂配置和称量方式。
- 首个基线样本所在应用时区日（`APP_TIMEZONE`，默认 `Asia/Tokyo`）起的连续7天为训练窗口。首周须有7个不同日的有效记录，数值维度至少6条；共享阶段须晚于完整窗口。未完成时提示尚缺完整基线，不伪装为健康判断。首周不足需补录真实缺漏或以新的猫砂配置版本重建，不能用共享记录补足。
- 正常基线使用中位数与 `max(1.4826 × MAD, 测量下限)`；下限为重量5g、直径0.5cm、等级0.6。
- 首周冻结，后续共享/隔离数据不会把持续异常学成正常。未来的基线记录不能解释时间更早的共享样本。
- 更换猫砂或称量方法会建立新版本，保留历史快照，新配置重建基线。

## 先发现共享异常

计算每块物理样本到每只猫正常基线的距离。数值偏差为 `z=(观测-中位数)/稳健尺度`；大便形态在基线占比低于10%时，分类偏差取4。

与至少一只猫基线相容时，保留正常共享观察，不指出属于谁。若对所有候选猫都至少有一个维度 `|z|≥3.5`，标为异常并报警。使用最大维度偏差避免不变维度稀释异常；模型比较损失使用平均平方距离。

一块异常即可报警，但不凭一块定位猫。仅总重量/总个数的混合汇总不会与单块基线比较。任一使用猫缺完整基线时保留采集，并提示完成训练。

## 差异算法

近3天、同盆、同配置、同类型、同使用猫名单的共享样本构成观察集合。正常模型包含所有猫的健康基线簇，每个样本的损失为到最近簇的平均平方稳健距离。

先算整体损失 `L0`，再用异常样本中位特征替换第 k 只猫的基线簇、保留其他猫正常簇，得到 `Lk`。改善量 `Gk=max(0,L0-Lk)`；`支持分=100×Gk/ΣG`。

其他正常样本提供其余猫仍呈现正常特征的线索。以下条件全部满足时显示优先排查候选：

- 至少2块异常，总有效样本数不少于猫数；
- 基线之间有可区分的数值维度，距离至少2倍尺度；
- 首名支持分≥70，与次名差≥20，整体残差改善≥1；
- 每只其他猫都具有与其正常基线相容、与其他基线损失差≥1的样本支持。

支持分是相对解释分，**不是患病概率或身份概率**。候选仅决定排查优先级，原共享记录始终保持 `CatID=null`。

合成例：A 约40g/4cm，B 约80g/7cm；共享采集有两个40g/4cm正常样本、两个15g/2cm异常样本。替换B可保留A正常样本的解释，因此优先排查B。单元测试验证了此反事实比较，**不代表实际识别准确率**。

## 报警边界

基线重叠、采集不完整、多个猫同时变化、同一猫间歇异常等情况下可能无法定位，排序也可能受模型假设影响。当前模型假设窗口内相对稳定，异常近似一个基线簇的改变，不提供保证。

全部有效样本均异常时附加整体偏移提示：可能是共同变化、猫砂/称量方式不一致或采样偏差；保留报警，不认定单猫或自动扣除环境效应。血迹、用力排尿而无产出直接紧急提示，不依赖训练。

没有记录不等于没有排泄，缺少某个正常簇不能证明对应猫无尿。建议连续异常或高支持候选出现后短期分开复核，或结合目击、RFID/摄像身份检查。尚无硬件接入或临床验证。

体重按指定猫统计；已目击的个体观察保留个人历史变化检测，与共享池7天基线分开。

## 参考依据

稳健尺度参照 [NIST MAD/缩放 MAD](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/mad.htm)。共享池反事实模型、窗口和阈值为本项目工程设计，未做临床校准或真实标注数据准确率评估。

[AAHA/AAFP 猫砂盆指导](https://www.aaha.org/resources/2021-aaha-aafp-feline-life-stage-guidelines/general-litter-box-considerations/)支持关注多猫配置与个体偏好；[Cornell 下泌尿道疾病资料](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-lower-urinary-tract-disease)支持少尿/无尿伴用力时的紧急提示。这些机构未验证或认可本项目定位算法。
