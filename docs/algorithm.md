# 多猫共盆：归属线索与异常观察

## 能识别什么

仅凭铲出的尿团重量、个数、直径与松散度，**无法保证**定位到某一只猫。体重接近、相同饮食、混合收集和猫砂差异都可能使特征不可区分。本项目提供透明、保守的辅助观察算法，不声称有经过临床验证的识别准确率。

目击、独立摄像身份核对、RFID/芯片身份识别可以提供确认归属。现场体重仅作为额外匹配线索；同体重猫仍可能无法区分。本版支持手工输入现场体重，尚未接入硬件。**匹配建议始终不会自动写入 CatID。**

## 数据隔离与快照

每条记录保存表格、猫砂盆、当时的使用猫名单、猫砂 ID/版本、猫砂名称与等待称量时间。修改猫砂配置产生新版本，历史快照保持不变；编辑记录归属不会重写猫砂快照。新记录使用当前配置，补录旧事件时须先选择对应历史配置（本版 UI 未提供历史版本选择，补录跨换砂日期的记录须谨慎）。

匹配基线的分组是 `猫 × 猫砂盆 × 猫砂配置版本 × 尿/便类型`。只使用时间上早于目标记录的、人工确认归属的单份记录；混合收集、未知归属和无产出记录均不参与特征学习。查询数据始终限定 TableID。

## 归属建议

1. 使用目标事件前28天同组数据，每个维度至少6条有效样本。
2. 数值基线使用中位数 μ 与 `max(1.4826 × MAD, 测量下限)`。下限：重量5g、直径0.5cm、1–5等级维度0.6；避免零方差产生无限分数。
3. 各维度距离平方求平均，`匹配分 = 100 × exp(-0.5 × 平均平方距离)`。现场独立测得的猫体重与事件前7天最近一次确认称重比较，容差0.15kg，权重2。
4. 至少2个加权证据、所有使用猫均有可用基线、最高分≥65、与第二名差≥20，才提示“建议核对”；否则保持“未知”。单个候选缺少基线，不能靠排除法确认其他猫。
5. **匹配分不是概率。** 正常特征可能把异常猫匹配到另一只正常猫，因此所有推断记录仍留在盆级数据中；只在人工身份确认后进入单猫统计。

## 个体差异与共同变化

- 近3天人工确认的同组记录中位数，与这3天之前28天的个人基线比较。历史至少6条，绝对稳健 Z ≥3.5 时产生观察提醒，并显示基线/近期样本数与实际值。
- 同盆、同猫砂版本、同类型、同指标里，至少2只猫出现同方向变化，标记“同盆共同变化”。共同变化可能源于测量方式、环境或共同健康变化，**保留每只猫的原始提醒，不消除警报**。
- 大便形态为分类维度：同组历史至少6条、常见形态占比≥70%，最新形态变化时提醒；共同变化还要求新的形态相同。
- 体重比较最近一次称重与7–30天前参考称重，变化≥5%时提示复称。幼猫成长、饮食或计划减重都可能触发，阈值不是临床诊断线。
- 无身份记录出现“排尿用力 + 无产出”或血迹时，发出盆级提醒，不能归罪于某只猫；有身份时发出单猫提醒。医疗症状不依赖统计样本数。
- 没有记录不等于没有排泄：手工记录的完整性不可保证，且未知归属会影响计数。本版展示实际记录次数，不依据缺失记录自动断言单猫少尿/无尿。需要连续身份监测及观察完整性标注才能扩展这种检测。

默认阈值是可解释的工程启发式，尚未经过临床校准。当前在源代码中设置非敏感阈值；后续可依据标注数据进行留出验证，评估误报率和漏报率。

## 参考资料

- [NIST：MAD 与缩放 MAD](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/mad.htm)：解释为何用稳健尺度处理极端观测。
- [AAHA/AAFP：猫砂盆考虑事项](https://www.aaha.org/resources/2021-aaha-aafp-feline-life-stage-guidelines/general-litter-box-considerations/)：多猫家庭建议提供足够、分散、易到达的猫砂盆，并关注个体猫砂偏好。本项目允许共用盆，不以共用作为最佳配置建议。
- [Cornell：猫下泌尿道疾病](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-lower-urinary-tract-disease)：排尿用力、反复尝试而少尿或无尿需紧急就医。项目的紧急提示依据此观察描述，而非尿团统计推断。

上述资料支持统计方法与观察边界；**不代表机构验证或认可本项目的识别算法。**
