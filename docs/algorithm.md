# 时间模型与共享池批次差异算法 v2

本项目使用 `time-mixture-v2`，是尚未做真实异常数据校准的工程模型。目标是发现共享池变化、排序排查候选；共享记录始终不写入猫咪身份，正常相容也不证明某只猫健康。

## 采集字段与操作

每行是一份物理样本，批次最多30份，尿团与大便分开建模。

| 字段 | 用途 |
|---|---|
| `occurred_at` | 采集/观察时间，保留旧字段兼容性，不冒充未知排泄时间 |
| `formed_at` | 真实形成时间；不知道就空，不用猫砂的配置等待时间代替 |
| `last_cleaned_at`、`last_cleaning_complete` | 只有确认上次彻底清理，才能将未知存放时长限定在两次清理之间 |
| `collection_complete` | 本次是否完整采集；未确认时不得升级为单猫优先候选 |
| `integrity` | complete / fragmented / adhered / mixed / unknown；不完整样本保留，但不进入普通高置信度推断 |
| `event_id` | 同份样本多次称量用同一编号；不等于排泄次数，未记录形成过程时不作次数推断 |
| `identity_method` | isolated / witnessed / device / manual / unknown；基准只接受独立确认的前三种 |
| `baseline_version` | 同一猫砂配置下可明确开启新基准版本，旧记录保留 |
| `length_cm`、`width_cm`、`thickness_cm` | 尿团长短轴/厚度；大便长度与横截面直径分开 |
| `litter_depth_cm` | 采集条件；基准厚度混用或部分缺失会阻止高置信度比较 |

现有重量、尿团直径/松散度、大便干湿/形态/大小与症状字段保留。重量是团块重量，不未经校准换算尿液体积。松散度建议固定铲取、筛落动作，按现有五级文字描述一致记录。

时间必须满足形成时间不晚于采集时间；确认彻底清理时，形成时间不能早于该清理时间。同一事件的猫、类型与已知形成时间不得冲突。同批次清理条件与厚度须一致，失败整批回滚。

## 七天进度和基准质量

基准按猫 × 尿/便 × 猫砂版本 × 基准版本隔离。最早七个独立有效采样日结束后冻结训练范围；缺一天可延长采集，不再把最初七个连续日期的缺漏永久锁死。同一天多条仍算一天。同事件重复测量只计一份，已知形成时间时按形成日计数。

首次测量用于独立样本统计；同一训练窗口内的重复测量另外用于时间模型。之后的共享记录、后续基准记录和窗口外重复测量均不训练已完成版本。分析只使用观察集合最早采集时刻之前的数据，避免拿未来基准解释过去样本。新基准版本可在同猫砂下重建；新版本尚未完成时明确提示，不用旧模型冒充新条件已验证。

界面分别显示覆盖 n/7天、独立事件数、典型数值、正常可分性、存放时间覆盖、老化曲线和异常定位验证状态。七天完成只表示可生成正常候选基准。

`quality.state` 为 collecting / ready / legacy_quality / conditions_mixed。旧数据缺少身份方式或完整性时保留基础观察，不伪装成完整训练数据。`localization_validation` 永远为 unvalidated；没有真实已确认异常标签的盲测，不显示“定位已验证”。

## 正常密度模型

尿团、大便独立训练，不因同盆同批就绑定身份。

数值特征用重量、直径、长轴、短轴、厚度的对数，训练中心取稳健中位数，尺度取 MAD 与测量下限的较大值。重量对数尺度下限为 max(0.05, log(1+5g/典型重量))，尺寸对数下限0.08。显示用的原始重量/直径中位数保留。

共享标准化的猫内残差估计协方差，固定0.5收缩到单位阵；样本不足 2d+3 时用单位阵，最多5维。共同可训练维度才能参与跨猫比较，缺少可选数值时使用协方差子矩阵边缘化。该收缩强度是初始工程参数，尚未由真实数据选择最优值。

松散度、干湿、大小、形态用五分类加一平滑分布，不把等级假设为等距。按存放区间 0—1、1—6、6—24、24—72、72小时以上分组；同事件在同区间最多计一次。区间不足6个事件时，该分类维度不参与时间校正后的密度判断，避免用新鲜样本的形态硬解释老样本。

## 时间模型

只用身份独立确认、完整且形成时间已知的同份样本重复测量：对各对数数值特征，计算样本内变化/小时，先按事件取中位数，再按事件汇总，避免某份样本多次测量获得过大权重。配对间隔至少1小时、形成时间和厚度一致；至少3个独立配对事件才能拟合线性老化斜率。

初版同类型、同猫砂配置共用实测老化曲线，个体正常中心独立。共用规律是待验证简化假设；仍要求每只猫至少3份形成时间已知的基准事件。没有配对数据时不写死衰减系数，只在已测时长附近作比较。

模型表达为：log(x) = 猫的正常中心 + 实测斜率 × 存放小时 + 波动。

形成时间已知用实际时长。未知但确认上次彻底清理时，在 [0, 清理间隔] 上用9点梯形权重计算密度。另以偏近期、偏早期的指数权重重算候选及各批次假设。每种时间假设均重新拟合变化参数；结论不一致拒绝单猫定位。

覆盖范围外不外推（已拟合曲线容差0.25小时，只有实测时长无曲线时容差1小时）。缺上次彻底清理确认、关键重量、完整性或基准质量时，不进入校正后的高置信度推断。未校正 MAD 偏差只能输出“测量变化，待复测”，不能包装成时间已排除后的健康异常。

## 单块变化与批次比较

时间覆盖内，对所有猫正常模型都至少有数值偏差≥3.5倍尺度，或足够分类数据支持未见形态，才标记单块异常。相容样本不确定归属；不同时间假设下的合理来源取并集，只保留候选集合。

近3天同盆、同猫砂配置和使用猫名单构成窗口，按事件编号去重。至少4个可比较事件且至少2只猫，开始批次差异分析。比较：

1. healthy：正常混合，使用比例可变化。
2. cat_change：某只猫保留正常成分，同时有偏移成分，变化比例在0.25、0.5、0.75、0.95中搜索，不能假设整只猫的正常特征消失。
3. common_shift：所有猫的数值中心共同偏移，不认定环境一定是原因。
4. unexplained：正常混合加10%宽分布污染项，用于拒绝单猫解释；此版未训练具体的多猫疾病或异常类型模型。

偏移位置从观察残差的五个分位点生成候选。混合使用比例以软 EM 估计，弱对称伪计数0.5，25轮；不平均分配猫数，也不用剩余块数确认身份。

按整窗对数密度比较，并按新增中心维度与变化比例增加 0.5 × 参数数 × log(事件数) 的复杂度惩罚。改善小于3保持相容。面板显示各假设的证据改善；这些是惩罚后的工程比较分，不是校准概率或严格贝叶斯证据。

只有以下全部满足，才显示暂定“优先排查”：至少2个实际批次、完整采集确认、正常特征可区分、按日留出有足够覆盖且无已观察错认、时间假设稳定、其余猫有可区分正常样本支持、领先所有正常/共同/其他候选模型至少2个证据单位。基线的区分阈值为2倍稳健尺度。阈值均待真实盲测校准。

不存在数据就绪时不会捏造模型比较。整体共同偏移或解释不足保留报警，不强制指定猫。血迹、排尿用力却无产出继续由独立症状规则提示，不等待模型训练。

## 验证和限制

正常验证按完整事件与采样日留出，老化曲线、中心和协方差都重新训练；同事件碎片/重复测量不会跨训练测试。分别记录评估事件数、给候选的覆盖数与错认数，不能把正常验证当成异常定位准确率。样本少时标记待评估。

单元测试包含已知/未知存放时间、正常老化、时间超范围、缺清理确认、厚度变化、混合拒绝、重复事件、独立七日覆盖、版本重建、未来泄漏保护、正常留出验证、部分变化、多批次暂定候选以及身份碰撞。PostgreSQL HTTP 测试覆盖字段持久化、时间/事件约束、权限和整批原子性；Docker CI 真正构建并启动三服务。

完全相同的输入无法确定来源。异常落进另一只猫健康分布、仅改变使用比例、漏采或多个猫同时改变时，本模型仍可能漏报或不能定位。没有记录不能推断无排泄；物理块数不当作排泄次数。线性老化、高斯近似、共用曲线、先验和阈值都需要真实数据检验。

后续验收须做真实混养盲测与已确认身份的异常样本验证，同时报告误报率、候选错认率、覆盖率和异常定位完成率；目前没有这样的真实准确率。
