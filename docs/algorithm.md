# 时间模型与联合多猫差异算法 v3

本项目使用 `joint-mixture-v3`，是尚未做真实异常数据校准的工程模型。目标是发现共享池变化、排序排查候选；共享记录始终不写入猫咪身份，正常相容也不证明某只猫健康。

## 采集字段与操作

每行是一份物理样本，批次最多30份，尿团与大便分开建模。

| 字段 | 用途 |
|---|---|
| `occurred_at` | 采集/观察时间，保留旧字段兼容性，不冒充未知排泄时间 |
| `formed_at` | 真实形成时间；不知道就空，不用猫砂的配置等待时间代替 |
| `last_cleaned_at`、`last_cleaning_complete` | 只有确认上次彻底清理，才能将未知存放时长限定在两次清理之间 |
| `collection_complete` | 本次是否完整采集；未确认时不得升级为单猫优先候选 |
| `integrity` | complete / fragmented / adhered / mixed / unknown；不完整样本保留，但不进入普通高置信度推断 |
| `event_id` | 同份样本多次称量用同一编号；不等于排泄次数，未记录形成过程时不作次数推断 |
| `identity_method` | isolated / witnessed / device / manual / unknown；基准只接受独立确认的前三种 |
| `baseline_version` | 同一猫砂配置下可明确开启新基准版本，旧记录保留 |
| `length_cm`、`width_cm`、`thickness_cm` | 尿团长短轴/厚度；大便长度与横截面直径分开 |
| `litter_depth_cm` | 采集条件；基准厚度混用或部分缺失会阻止高置信度比较 |

现有重量、尿团直径/松散度、大便干湿/形态/大小与症状字段保留。重量是团块重量，不未经校准换算尿液体积。松散度建议固定铲取、筛落动作，按现有五级文字描述一致记录。

时间必须满足形成时间不晚于采集时间；确认彻底清理时，形成时间不能早于该清理时间。同一事件的猫、类型与已知形成时间不得冲突。同批次清理条件与厚度须一致，失败整批回滚。

## 七天进度和基准质量

基准按猫 × 尿/便 × 猫砂版本 × 基准版本隔离。最早七个独立有效采样日结束后冻结训练范围；缺一天可延长采集，不再把最初七个连续日期的缺漏永久锁死。同一天多条仍算一天。同事件重复测量只计一份，已知形成时间时按形成日计数。

首次测量用于独立样本统计；同一训练窗口内的重复测量另外用于时间模型。之后的共享记录、后续基准记录和窗口外重复测量均不训练已完成版本。分析只使用观察集合最早采集时刻之前的数据，避免拿未来基准解释过去样本。新基准版本可在同猫砂下重建；新版本尚未完成时明确提示，不用旧模型冒充新条件已验证。

界面分别显示覆盖 n/7天、独立事件数、典型数值、正常可分性、存放时间覆盖、老化曲线和异常定位验证状态。七天完成只表示可生成正常候选基准。

`quality.state` 为 collecting / ready / legacy_quality / conditions_mixed。旧数据缺少身份方式或完整性时保留基础观察，不伪装成完整训练数据。`localization_validation` 永远为 unvalidated；没有真实已确认异常标签的盲测，不显示“定位已验证”。

## 正常密度模型

尿团、大便独立训练，不因同盆同批就绑定身份。

数值特征用重量、直径、长轴、短轴、厚度的对数，训练中心取稳健中位数，尺度取 MAD 与测量下限的较大值。重量对数尺度下限为 max(0.05, log(1+5g/典型重量))，尺寸对数下限0.08。显示用的原始重量/直径中位数保留。

共享标准化的猫内残差估计协方差，固定0.5收缩到单位阵；样本不足 2d+3 时用单位阵，最多5维。共同可训练维度才能参与跨猫比较，缺少可选数值时使用协方差子矩阵边缘化。该收缩强度是初始工程参数，尚未由真实数据选择最优值。

松散度、干湿、大小、形态用五分类加一平滑分布，不把等级假设为等距。按存放区间 0—1、1—6、6—24、24—72、72小时以上分组；同事件在同区间最多计一次。区间不足6个事件时，该分类维度不参与时间校正后的密度判断，避免用新鲜样本的形态硬解释老样本。

## 时间模型

只用身份独立确认、完整且形成时间已知的同份样本重复测量：对各对数数值特征，计算样本内变化/小时，先按事件取中位数，再按事件汇总，避免某份样本多次测量获得过大权重。配对间隔至少1小时、形成时间和厚度一致；至少3个独立配对事件才能拟合线性老化斜率。

初版同类型、同猫砂配置共用实测老化曲线，个体正常中心独立。共用规律是待验证简化假设；仍要求每只猫至少3份形成时间已知的基准事件。没有配对数据时不写死衰减系数，只在已测时长附近作比较。

模型表达为：log(x) = 猫的正常中心 + 实测斜率 × 存放小时 + 波动。

形成时间已知用实际时长。未知但确认上次彻底清理时，在 [0, 清理间隔] 上用9点梯形权重计算密度。另以偏近期、偏早期的指数权重重算候选及各批次假设。每种时间假设均重新拟合变化参数；结论不一致拒绝单猫定位。

覆盖范围外不外推（已拟合曲线容差0.25小时，只有实测时长无曲线时容差1小时）。缺上次彻底清理确认、关键重量、完整性或基准质量时，不进入校正后的高置信度推断。未校正 MAD 偏差只能输出“测量变化，待复测”，不能包装成时间已排除后的健康异常。

## 单块变化与联合组合比较

时间覆盖内，对所有猫正常模型都至少有数值偏差≥3.5倍尺度，或足够分类数据支持未见形态，才标记单块异常。相容样本不确定归属；不同时间假设下的合理来源取并集，只保留候选集合。

近3天同盆、同猫砂配置和使用猫名单构成窗口。使用名单有交集的窗口形成一个连通使用群，在同一组变化猫集合下合并各窗口对数密度。不同猫砂、尿/便、盆和名单分别保留自己的密度与混合比例；只合并证据，不将异常盆名单直接求交集。一次清理中尿团与大便也不绑定成同一只猫。

每个连通使用群支持2—10只猫，比较全部 2^N 种变化集合，包含没有猫变化的正常解释。10只猫为1,024种。集合 S 中的一只猫在至少一个窗口拥有变化成分；其他窗口可以正常，不要求尿和便同时变化。每只变化猫保留正常成分，变化比例从0.25、0.5、0.75、1中搜索；“某只猫还有正常样本”不能硬性排除该猫偶尔异常。

样本内数值残差、未见分类形态以及五个残差分位点产生变化原型，保留最多12个样本原型与分位点原型。只保留至少一个数值变化≥2倍尺度或训练覆盖内分类改变的原型，避免把完全未变的猫塞进异常组合。变化后的重量仍保持5g绝对称量噪声下限，防止大猫的较小对数尺度被错误用于小尿团，制造虚假的定位优势。

原型配合各变化比例先按单猫比较排序，每个不同残差原型至少保留一项，再补其他变化比例，每猫每窗口最多24个选项。只取单猫最优的若干项会漏掉“只有两只猫联合变化才解释得通”的次要异常峰，因此先保留不同原型。软 EM 估计窗口使用比例，弱对称伪计数0.5，12轮。每种集合使用邻近集合的拟合作为起点，最多两轮坐标优化；各窗口允许未变化选项，整群保持集合中每只猫至少一处有变化。**集合枚举完整，参数拟合为有界近似，并非完整贝叶斯积分或全局最优解。** 单异常原型也不能覆盖任意多峰疾病分布。

已目击、隔离或设备确认的后续样本以已知猫条件密度进入比较；仅人工猜测的标签不用来缩小来源。后续样本不进入冻结的正常训练范围。同一事件多次测量在联合窗口只用一次，优先身份独立确认的记录。未知来源的普通观察不冒充共享采集。

除集合模型外，仍比较所有猫共同数值偏移和正常混合加10%宽分布污染项。共同变化不自动等于环境原因；未知解释用于拒绝过于自信的个体归因。每个变化成分按 0.5 ×（数值维度数 + 改变的分类维度数 + 变化比例参数）× log(窗口样本数) 惩罚复杂度。证据改善小于3保持正常相容；共同/未知解释距最支持组合不超过2单位时保留全部猫，不强行定位。

所有时间先验下距该先验最优集合不超过4单位的变化集合均保留，候选范围取这些集合的猫咪并集。界面显示前12种组合，但并集使用全部合理集合；“A 或 B”与“A+B 同时变化”分别表达。工程比较分不是校准概率、严格贝叶斯证据或具备保证覆盖率的保形集合。

至少 max(4,N) 个完整可比较独立事件才开始组合拟合。近3天超过240个事件时明确标记受限，保留逐块观察，不悄悄截掉冲突样本。缺基准、缺时间覆盖、猫砂条件变化、不完整样本均不能制造定位证据。只要有未覆盖样本，不能据此排除其他猫。

## 观察时段、暂定定位和主动复核

一次清理拆成多个提交不算多次观察：有上次彻底清理时间的，按盆与该清理时间归并；没有时按盆与本次采集分钟归并。再将至少间隔1小时的采集时刻划为不同观察时段。该时间门槛是工程保护，不保证各时段在统计上独立，使用者仍需记录真实清理过程。

只有完整采集、至少两个观察时段、无遗漏的可比较样本、三个时间假设一致且共同/未知解释均被甩开、合理组合并集等于最支持集合，才可能升级为暂定单猫或暂定同时变化组合。各有关正常基准还需按日留出已评估、覆盖至少一半、无已观察错认；并不把任意两只猫基准重叠作为拒绝所有其他猫定位的总开关。依然是未验证的排查候选，不保存为样本身份。

对合理集合按 exp(惩罚后分数差) 建立内部比较权重，取前24种组合做确定性预测近似。在已覆盖的存放时长，模拟身份明确的复核样本，计算观察后的集合熵减少量，排序建议下一只应目击复核的猫以及尿/便类型。每猫只显示一项，最多三项；重复称量同样本不冒充新身份信息。近似信息增益仅用于建议排序，并非已校准的采样成功率。

在界面点击“记录复核样本”可预选猫、盆与类型；仍必须实际目击或隔离确认来源，填写真实形成与称量时间，不从候选猜身份。已知标签的新数据会重新比较整个使用群，保留正常与异常成分；并不因一次正常复核就排除间歇性异常。

## 后台协程与接口

采集保存接口只校验并持久化；数据读取通过 PostgreSQL 只读 repeatable-read 事务取得一致快照，提交给后台任务后立即返回。Gin 请求链不调用统计拟合。后台由一个工作协程消费32项有界队列，最多缓存128个表格的最新任务，计算无数据库连接也不持有数据库事务。

同表格、同快照、同5分钟时间桶复用任务与结果；同输入运行期间强制重算也去重。源数据写入会撤销该表格的旧任务，更新快照替换旧任务；取消后的旧结果不能发布。计算含取消检查，单任务上限2分钟，停止服务时取消后台工作。失败和 panic 不影响后续任务；队列满返回可重试状态，记录仍已保存。

- `GET /api/tables/:table/data` 返回原始数据、即时症状规则与 `analysis_job`；新快照不返回过期统计。
- `GET /api/tables/:table/analysis/:job` 返回进度、状态以及完成结果，每次都重新校验表格访问权限。
- `POST /api/tables/:table/analysis` 显式请求重算，返回相同结构；读取权限即可使用，仍受去重与队列容量限制。

状态为 queued / running / done / failed / deferred，进度由后台更新。页面约每1.5秒读取状态，完成后更新统计；切换表格、退出或销毁页面停止轮询，旧响应不能覆盖当前表格。失败/排队容量不足提供重试。排队和运行时明确显示尚未完成，血迹、用力无产出等直接症状规则立即可见，保存记录无需等待算法。

任务缓存为进程内存，不承诺重启后保留进度；重新加载数据会重新提交。单协程避免无界 CPU 争用，但多个表格同时请求会排队。超过预算只报告受限，不伪装成已完成；长期部署可换为持久队列或独立计算服务。

## 验证和限制

正常验证按完整事件与采样日留出，老化曲线、中心和协方差都重新训练；同事件碎片/重复测量不会跨训练测试。分别记录评估事件数、给候选的覆盖数与错认数，不能把正常验证当成异常定位准确率。样本少时标记待评估。

单元测试包含已知/未知存放时间、正常老化、时间超范围、缺清理确认、厚度变化、混合拒绝、重复事件、独立七日覆盖、版本重建、未来泄漏保护、正常留出验证、部分变化、2—10只猫、未标身份多猫变化、已确认身份复核、多盆联合、尿便可分别变化以及同次清理拆单。任务测试用受控阻塞计算验证提交立即返回、快照不可变、去重、取消、旧结果拒绝发布、队列上限、并发访问和失败恢复；CI race detector 检查数据竞争。PostgreSQL HTTP 测试覆盖字段持久化、时间/事件约束、权限、任务隔离与撤销、整批原子性；Docker CI 真正构建并启动三服务。合成测试检查实现行为，不代表真实异常定位准确率。

完全相同的输入无法确定来源。异常落进另一只猫健康分布、仅改变使用比例、漏采或多个猫同时改变或多个病理分布重叠时，本模型仍可能漏报或不能定位。没有记录不能推断无排泄；物理块数不当作排泄次数。线性老化、高斯近似、共用曲线、先验和阈值都需要真实数据检验。

后续验收须做真实混养盲测与已确认身份的异常样本验证，同时报告误报率、候选错认率、覆盖率和异常定位完成率；目前没有这样的真实准确率。
